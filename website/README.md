# Portfolio website

Next.js 16 app for Poshitha Adhikari's portfolio. Project mission, status and design rules: see [`../AGENTS.md`](../AGENTS.md).

```bash
npm install
npm run dev    # http://localhost:3000
npm run build
npm run lint
```

- Content: `src/data/site.ts`
- Sections: `src/components/`
- Design tokens and text styles: `src/app/globals.css`
